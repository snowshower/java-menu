### 8. 예외처리
**1. 코치 이름 입력 오류**
- null
  - "[ERROR] 올바른 코치 이름을 입력해 주세요."
- 이름 글자 수 2글자 미만 or 4글자 초과
  - "[ERROR] 코치 이름은 2글자 ~ 4글자여야 합니다."
- 코치 2명 미만 or 5명 초과
  - "[ERROR] 코치는 최소 2명 이상 입력해야 합니다."
**2. 못 먹는 메뉴 입력 오류**
- null
  - "[ERROR] 올바른 메뉴를 입력해 주세요."
- 없는 메뉴 입력
  - "[ERROR] 없는 메뉴를 입력하셨습니다. 다시 입력해 주세요."


흐름
- 이름 리스트 입력받고
- 각 코치별로 못 먹는 메뉴 입력받고
- 코치 리스트 생성
      - 맵으로 <카테고리, 코치 리스트> 생성
- 맵으로 하면 안될듯 카테고리 중복 가능이라
- 리스트 두개 만들까 카테고리 리스트, 코치 리스트
- 서비스에서 void로 리스트 업데이트만 하고
- 출력뷰에 카테고리 리스트랑 코치 리스트 던지면 될듯?
- 서비스에서 카테고리 선정하기 전에 2개 넘었는지 확인하는 로직 필요
  - 카테고리 선정
  - 카테고리 리스트에서 선정된 카테고리가 2개 이상이면 다시 뽑기

  - 랜덤으로 카테고리 선정

  - 못 먹는 메뉴에 해당하는지 확인
    - 못 먹는 메뉴 아닐 때까지 셔플
  - 이미 먹은 메뉴인지 확인
    - 먹은 메뉴가 아닐 때까지 셔플
  - 먹은 메뉴 리스트에 추가
